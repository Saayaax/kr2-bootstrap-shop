# kr2-bootstrap-shop

## Контрольная работа №2

Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

## Описание

Проект представляет собой версию сайта интернет-магазина, разработанную с использованием Bootstrap.

## Используемые технологии

- HTML;
- Bootstrap 5;
- CSS;
- Git;
- GitHub.

## Структура проекта

- `index.html` — главная страница;
- `catalog.html` — каталог товаров;
- `product.html` — карточка товара;
- `order.html` — оформление заявки;
- `css/custom.css` — собственные стили поверх Bootstrap;
- `README.md` — описание проекта.
