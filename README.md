# kr2-bootstrap-shop — алкомаркет «Градус»

## Контрольная работа №2

Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

## Описание

Проект представляет собой учебную версию сайта алкомаркета «Градус», разработанную с использованием Bootstrap.
В каталоге — текила, водка и светлое пиво с фотографиями, описаниями и характеристиками.
Товары и цены вымышлены, продажа не осуществляется.

## Используемый фреймворк

Bootstrap 5.3.8.

## Способ подключения

Bootstrap подключён через CDN jsDelivr: в `head` каждой страницы подключается
`bootstrap.min.css`, перед `</body>` — `bootstrap.bundle.min.js`.
Собственный файл `css/custom.css` подключается после Bootstrap.

## Как посмотреть проект

- Онлайн: открыть ссылку GitHub Pages (см. ниже).
- Локально: скачать репозиторий и открыть `index.html` в браузере
  (нужен интернет, так как Bootstrap подключён через CDN).

## Структура проекта

- `index.html` — главная страница;
- `catalog.html` — каталог товаров;
- `product.html` — страница товара;
- `order.html` — форма заявки;
- `css/custom.css` — дополнительные стили проекта;
- `js/main.js` — проверка форм, сообщения об успешной отправке и окно подтверждения возраста;
- `images/` — фотографии товаров (`tequila.jpeg`, `vodka.jpeg`, `beer.jpeg`) и фон сайта (`beer-bg.jpg`);
- `README.md` — описание проекта.
